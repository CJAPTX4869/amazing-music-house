## 1. 项目概况

音乐播放平台（对标网易云 Web 版），三端结构：

| 端 | 位置 | 技术栈 | 端口 | 说明 |
|---|---|---|---|---|
| Web 前端 | `vue3-cloud-music-master/` | Vue3 + TS + Pinia + Naive UI + Vite + UnoCSS | 5175 | 主力端，功能最全 |
| 后端 | `music-platform/music-server/` | Spring Boot + MyBatis-Plus + MySQL + JWT | 8080 | 自有 API + 网易云兼容层 |
| 安卓客户端 | `koi_music/`（MusicProject 下） | 原生 Android | - | **尚未与后端对接**，仍指向已下线的百度 Ting 接口（阶段 2 改造范围） |

- 数据库：MySQL `music_db`（root/root 本地开发），脚本在 `music-server/src/main/resources/db/`
- 静态存储：`music-server/storage/`（avatar 头像 / cover 歌单封面 / comment 评论配图 / emoji 表情包，按 `yyyy/MM/dd/uuid.ext` 组织）

### 启动方式
- 后端：`mvn -o spring-boot:run`（**离线参数 -o 必带**）；独立自测实例：`-Dspring-boot.run.arguments=--server.port=8081`
- 前端：`npm run dev`（Vite，5175）
- 注意：本地 8080 目前是**命令行实例**；若用户要用 IDEA 调试，先停命令行实例（`Get-NetTCPConnection -LocalPort 8080` 找 PID → `Stop-Process`）

## 3. 数据库设计

核心表（脚本 `db/schema.sql`，迁移 `db/migration-v3.1.sql`，表情导入 `db/emoji-init.sql`）：

| 表 | 关键字段/设计 |
|---|---|
| `sys_user` | avatar（存储相对路径）、signature、region、role(0/1) |
| `song` | **like_count / comment_count**（原子 `GREATEST(col±delta,0)` 维护） |
| `playlist` | user_id、type(0 普通/1 我喜欢的音乐)、**status(1 公开/0 私密)**、song_count、collect_count、cover_path；`(user_id,type)` 唯一约束 |
| `song_comment` | song_id、user_id、**parent_id 恒指根评论** + reply_user_id（回复@谁）、content、image_path、like_count、deleted（逻辑删整楼） |
| `comment_like` | comment_id + user_id（幂等去重） |
| `user_follow` | follower_id + followee_id + status(PENDING/ACCEPTED)，**好友制**（双向 ACCEPTED=好友） |
| `playlist_collect` | playlist_id + user_id（收藏歌单，唯一约束） |
| `emoji` | 73 条 Twemoji：中文名 ↔ 码点 ↔ 文件路径 |
| `playlist_song` | 歌单-歌曲关联；「我喜欢的音乐」= type=1 歌单，喜欢歌曲即插入该歌单 |

## 4. 后端接口清单

### 4.1 鉴权机制（审查重点）
- `JwtInterceptor`：类/方法级 `@RequireLogin`/`@RequireAdmin`；**方法级 `@PublicApi` 免除类级登录要求**（图片等匿名读取场景）
- `preHandle` 入口 `UserContext.clear()` 兜底（防 ThreadLocal 泄漏串号——已修复，勿回退）
- 业务错误统一 HTTP 200 + body.code（401=登录失效，前端响应拦截器处理）

### 4.2 自有 API（前缀 `/api`）
- 认证：`/auth/login|register|profile`
- 歌单：`/playlists` CRUD（POST 支持 **privacy:1 私密**）、`/{id}/cover` POST 上传/GET 公开读取、`/{id}/collect` 收藏/取消 + `/check`、`/users/{id}/playlists` 主页歌单（created/favorite/collected 三组）
- 歌曲：分页/详情/`/songs/{id}/cover`
- 评论：`/comments`（歌曲评论 CRUD、楼中楼回复、点赞 `/like`、配图上传/`GET /comments/image?path=` 预览——**仅允许 comment/ 前缀防路径穿越**）
- 表情：`/emojis` 清单 + 图片直出（73 个 Twemoji）
- 关注：`POST/DELETE /users/{id}/follow`、`/accept`、`GET /{id}/follow/status`、`GET /users/follow/requests`
- 用户：`/users/{id}/profile`（公开资料，关注/粉丝计数）

### 4.3 网易云兼容层（`/api/` + 旧前端字段格式）
- `/cloudsearch`（**type=1000 歌单搜索 + offset 翻页已支持**）、`/search/suggest`、`/top/song`（带 likeCount/commentCount）
- `/playlist/detail?id=`、`/song/url/v1`（data[0] 完整歌曲 map）、`/check/music`、`/lyric?id=`、`/user/playlist?uid=`（favorite+created+collected 合并，收藏项带 subscribed）、`/likelist?uid=`
- 转换规则：`LegacyConvertUtils`，**所有图片/封面输出绝对地址**（旧前端独立端口 5175，相对路径会 404）

## 6. 关键业务流程

### 播放链路（前端最复杂）
1. 播放全部/双击行 → `changePlayIndex` → 无 url 则 `setMusicData`（`/song/url/v1`）→ blob 缓存（IndexedDB）
2. 随机模式：`rawPlayList`（原始顺序）存 localStorage，`playList` 被打乱；切回顺序模式从 rawPlayList 恢复（**已加防御：rawPlayList 缺失/坏数据/当前歌不在其中→不切换仅重算索引**）
3. 相邻索引：`initPlayListPrevAndNextIndex` 维护每首歌 prev/next；**addPlaylist 后必须重算**（已修）
4. 失败重试：audio error code 2/4 → 重取一次（MAX_RETRY_COUNT=1，**换歌自动重置**）；isLoad 在 try/finally 复位（已修）

### 上传链路（头像/封面/评论配图同一套）
前端 `validateImageFile` → 压缩（`compressToSquare` 方图 / `compressKeepRatio` 等比，GIF 跳过）→ FormData → 后端 `storeXxx`（先落盘→入库→失败补偿删新→成功删旧）→ 前端回显 `baseURL + apiPath + ?v=时间戳`（破缓存）

### 评论计数
- 发评/删评：song.comment_count 原子 ±1（删根评论连带整楼逻辑删并扣减）
- 喜欢/取消：favorite/unfavorite 维护 song.like_count
- 点赞评论：comment_like 幂等 + comment.like_count

## 8. 项目约定与坑（⚠️ 改代码必读）

**A. 深色模式样式**：scoped 里 `:global(html.dark) .xxx` 编译后规则**直接丢失**（本项目实测）→ 一律写 **App.vue 全局样式** `html.dark .xxx`

**B. naive-ui 菜单**：`.n-menu-item-content` 是 **CSS Grid 不是 Flex**（flex:1 无效）；行右侧元素用 **absolute**（content 加 relative）；`MenuOption.extra` 槽位会渲染到**第二行**——不要用来做行内右侧按钮

**C. 图片类接口必须匿名**：`<img src>` 不带 Authorization 头 → 图片读取接口必须 `@PublicApi`（类级 @RequireLogin 的 Controller 里）

**D. 兼容层图片必须绝对地址**：旧前端 5175，相对路径指向自身 404 → 一律 `baseUrl + /api + path`

**E. CSS 改动验证**：HMR 部分规则不更新 + `:deep()` 编译依赖祖先 scope 属性 → **改 CSS 后必须整页 reload 再查 computed**，不要信 HMR 即时表现

**F. vue-tsc 不报未闭合 HTML 注释**（红屏事故根因）→ 关键改动后看 Vite 页面编译状态，别只信 tsc

**G. hutool 5.8**：图片缩放用 `Img.from(file).scale(w,h).write()`；`ImgUtil.scale(File,File)` 该重载不存在

**M. 表情/编码**：评论表情是 `[中文名]` 占位符存储（非 Unicode emoji），渲染时替换为 Twemoji `<img>`（无 v-html 防 XSS）；接口测试中文必须 `[Text.Encoding]::UTF8.GetBytes(body)` + charset=utf-8

**I. 测试脚本**：PowerShell `$pid` 是只读自动变量；`mvn -o` 离线；mysql -e 中文用 `source` 文件最稳

**J. 部署/换环境**：需执行 `migration-v3.1.sql` + `emoji-init.sql` + 同步 `storage/emoji/`
