# 01 · 客户端（听歌端）功能分析

> 分析对象：`D:\Desktop\MusicProject\vue3-cloud-music-master\`
> 定位：面向**普通用户**的听歌 Web 应用。技术栈：Vue 3.5 + TypeScript + Vite 5 + Naive UI + Pinia + Tailwind。
> 端口：**5175**（dev）。启动：`npm run dev`。构建：`npm run build`。
> 与后端的关系：**只消费接口，不做任何权限与业务判定**；所有数据来自 `http://localhost:8080/api`（写在 `src/service/request.ts`）。

## 2. 路由表（功能入口）

| 路径 | 页面组件 | 需登录 | 说明 |
| --- | --- | --- | --- |
| `/` → `/discovery` | DiscoveryView | 否 | 发现页（默认首页） |
| `/songList` | RecommendSongListView | 否 | 歌单广场 |
| `/songList/:id` | SongListDetail | 否 | 歌单详情（未登录也能看，操作时提示登录） |
| `/songList/edit/:id` | EditSongList | **是** | 歌单编辑 |
| `/latestMusic` | LatestMusicView | 否 | 最新音乐 |

守卫说明：路由守卫只做**体验层拦截**（未登录弹提示/引导），真正的鉴权边界在后端接口上。

## 4. 数据流与状态管理

### 4.1 请求层（`service/request.ts`）

```
baseURL: http://localhost:8080/api
请求拦截：localStorage 有 music_token → 注入 Authorization: Bearer <token>
响应拦截：body.code === 401 → 清 music_token/isLogin/userProfile + 提示 + 广播 authExpired
```

要点（历史踩坑）：后端**业务错误恒返回 HTTP 200**，错误码在 `body.code`，所以**不能只靠 axios 错误拦截器**。

### 4.2 播放核心流程（`stores/main.ts`）

```
双击歌曲 → useDbClickPlay → initPlayList(data, index, listId)
  → setMusicData：/check/music → 通过则 /song/url/v1 取地址 → /lyric/new 取歌词
  → 写入 playList（过滤 fee=0）→ currentPlayIndex → FooterPlayer 的 <audio> 开始播放
切歌 → toggleNext/togglePrev → changePlayIndex（无 url 的先补地址）
播放模式 → shufflePlayList / order / singleLoop
```

持久化：`playList / currentPlayIndex / playMode / likeSongs / theme / appBgImage / appBgMask` 全部落 localStorage，刷新即恢复。

### 4.3 跨组件通信

- `utils/obverser.ts`：轻量事件总线（`authExpired`、登录态变更广播）
- `window.$message`：Naive UI 全局消息（App.vue 挂载）
- `localStorage.userProfile`：登录态镜像（多处读写，注意同步）

## 6. 已知问题与注意事项

1. `updatePlayListInfo`（编辑歌单信息）是**前端空实现**，调用方应视为未开放。
2. `CommentList` 无后端数据源，永远空态。
3. `views\mv\` 与 `MvList\` 是 MV 功能废弃后的残留，无路由可达。
4. 播放地址会被追加 `?id=`（`store.setMusicData`），因此后端返回的 URL **不能自带 query**。
5. 全局 keypress 监听（FooterPlayer 空格键）必须过滤输入框 —— 已修复，改动时勿回退。
6. `searchResult` 路由未设 `meta.auth`，属于公开页。
7. `useValidateVipSong` 依赖歌曲 `fee` 字段：后端翻译层固定返回 **8**（可播放），改成 0/1 会导致整表被过滤或误判 VIP。
