## 二、按文档修复的真实缺陷（`docs/05` 第四节「安卓客户端问题清单」）

| 编号 | 问题 | 危害 | 处理 |
| --- | --- | --- | --- |
| #2 | `PlayFragment.onBufferingUpdate` 用 `percent` 做除数、公式反向 | **percent=0 时 ArithmeticException 崩溃** | 加 0/上限保护 + 修正公式 |
| #1 | `MusicInfoActivity` 空判后缺 `return` | **NPE 崩溃** | 补 `return` |
| #9 | `PlayService` 无 `onDestroy` | MediaPlayer/通知/定时器不释放 | 补 `onDestroy` |
| #8 | `AlbumCoverView` 自循环动画未随视图停止 | 泄漏 + 耗电 | `onDetachedFromWindow` 停动画 |
| #7 | `PlayFragment` 音量广播注册/反注册不对等 | 重复注册、多次响应 | 改为 onResume/onPause 配对 + 标志位 |
| #18 | `NoisyAudioStreamReceiver` 无条件 `playPause()` | 空闲时拔耳机**反而开始播放** | 仅 `isPlaying()` 时暂停 |
| #20 | `Notifier.findTextColor` 循环未更新 `maxTextSize` | 通知栏文字颜色判断错误 | 补赋值 |
| #22 | `DownloadMusic` 把扩展名当 MIME | 下载文件 MIME 错误 | 改查 `MimeTypeMap` |

| 附带 | 下载把 flac/wav 存成 `.mp3` | 扩展名与内容不符 | 改用服务端原始文件名 + 文件名消毒 |

## 五、账号规则（客户端禁止管理员登录）

> 需求：**管理员账号（`role=1`，如 `admin`）不允许登录客户端；只有普通用户（`role=0`）可以。**

实现位置与逻辑：

| 位置 | 逻辑 |
| --- | --- |
| `activity/LoginActivity.doLogin()` | 登录成功后检查 `user.role`；若为 1 → **不保存 token**、清空本地登录态、提示"管理员账号不能登录客户端，请使用普通用户账号（可在本页注册）"，并**不关闭页面** |
| `activity/LoginActivity.refreshStatus()` | 进入登录页时若发现本地存的是管理员登录态（旧版本遗留）→ **自动强制退出** |
| `utils/ServerConfig` | 新增 `ROLE_USER/ROLE_ADMIN` 常量与 `role` 持久化（`setRole/getRole/isAdminLoggedIn`），`logout()` 一并清除 |
| 本地已登录用户的红心状态 | 登录/退出时调用 `FavoriteManager.clear()`，避免上一个账号的收藏残留 |

**实测证据（模拟器）**

| 场景 | 结果 | 判据 |
| --- | --- | --- |
| 用 `admin` / `admin123` 登录 | ❌ **被拒绝** | `server_config.xml` 里**只有 `base_url`，没有 `token`/`user_id`/`role`**；页面仍停在 LoginActivity（成功路径会在 800ms 后自动关闭） |
| 注册并登录 `client01` / `client123456`（普通用户） | ✅ **成功** | 本地落盘 `token` + `role=0` + `user_id=16` + `nickname=testuser`；服务端 `client01 → code=200 role=0` |

> ⚠️ 该限制目前是**客户端侧**校验（登录页拦截）。服务端 `/auth/login` 对管理员仍然放行（管理端 5174 需要它）。
> 若需要"服务端也拒绝管理员走客户端登录"，建议加一个专用端点（如 `POST /auth/client-login`，内部拒绝 `role=1`），我可以直接实现。

## 六、已知限制（不是本次改动引入的）

1. **高德天气需要重新注册 KEY**：高德 KEY 与「包名 + 签名 SHA1」绑定。
   当前包名 `me.wcy.music`，debug 签名 SHA1 = `70:E6:03:6B:3C:93:DB:79:1F:B0:25:7E:6E:A1:11:D3:F1:02:F1:8D`；
   另外项目自带的 `AMap_Location_1.3.3.jar` 是 2016 年的库，在新系统上兼容性一般。
2. **每次启动会请求定位权限**（天气功能所致）；不需要天气可在 `MusicActivity.updateWeather()` 里去掉。
3. **播放历史**：服务端 `play_history` 表从未写入，App 无法展示"最近播放"；要做只能本地存。
4. `targetSdk 25`（原项目设定）：明文 HTTP 可用；若提升 targetSdk 需补 `NotificationChannel`、`FLAG_IMMUTABLE`、`exported` 声明。
5. 文档 `docs/05` 中仍未处理的低风险项：`#10` AudioPlayer noisyReceiver 重复注册、`#11` Loader 生命周期、`#17` 播放列表删除当前项索引、`#21` `Music` 表名 `SystemMessage`、`#24` 重复扫描逻辑。
