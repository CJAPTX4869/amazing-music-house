## 四、安卓客户端（koi_music）问题清单

> 关键结论：客户端**仍指向百度 Ting 接口**（`tingapi.ting.baidu.com`，已下线），与自有后端**零对接**——这是已知的"阶段 2 安卓改造"范围，非新问题。

### 崩溃 / NPE（高危）
1. `MusicInfoActivity:71-75` `mMusic == null` 只 `finish()` 未 `return` → 紧接着 NPE
2. `PlayFragment:186-188` `onBufferingUpdate` **整数除零**（percent=0）+ 公式反向
3. `AutoLoadListView:76-83` `addFooterView` 在 `setAdapter` 之后调用 → 滑到底加载更多即崩
4. `ShareOnlineMusic:37-47` 未判 `getBitrate()` 为 null
5. `SheetAdapter:141` / `OnlineMusicActivity:172-176` 未判 `billboard` 为空
6. `WeatherExecutor:100` / `PermissionReq:184` 潜在 NPE

### 生命周期 / 泄漏
7. `PlayFragment`：`mVolumeReceiver` 在 `onResume` 注册、`onDestroy` 反注册 → 前后台切换重复注册
8. `AlbumCoverView`：`Handler` 自循环动画未在 `onDetachedFromWindow` 停止 → 泄漏 + 耗电
9. `PlayService` **无 `onDestroy`** → `MediaPlayer`/`MediaSession`/广播未释放
10. `AudioPlayer` noisyReceiver 重复注册（无状态守卫）
11. `LocalMusicFragment` + `MusicLoaderCallback` Loader 与 Fragment 生命周期绑定不佳

### 主线程 IO
12. `ImageUtils` 半径 50 高斯模糊**在主线程**（切歌卡顿/ANR 风险）
13. `CoverLoader.loadThumb` 在主线程解码（列表滑动、通知构建掉帧）

### 网络 / 播放
14. 硬编码第三方域名 + 明文 HTTP（无 BaseUrl 配置、无 `networkSecurityConfig`）
15. 未使用自有后端 `/songs/{id}/stream`（支持 Range/206）——客户端无断点能力
16. 下载用全量 `FileCallBack`，无 Range
17. `PlaylistActivity` 删除当前播放项：`setPlayPosition(pos-1)` + `next()` 在 LOOP 下跳歌错位
18. `NoisyAudioStreamReceiver` 在 IDLE 时调用 `playPause()` 反而**开始播放**
19. 无 `NotificationChannel`、`PendingIntent` 缺 `FLAG_IMMUTABLE`（提升 targetSdk 后必崩）

### 其它
20. `Notifier.findTextColor()` 循环从不更新 `maxTextSize` → 主题判断错误
21. `Music` 表名 `SystemMessage`（换皮遗留）+ GreenDAO `DevOpenHelper`（升级清库）
22. `DownloadMusic` 把扩展名当 MIME
23. `JsonCallback` 解析失败走 `onResponse(null)` 而非 `onError`（错误被吞）
24. `MusicUtils.scanMusic` 与 `MusicLoaderCallback` 两份重复扫描逻辑

### 与后端接口不一致（改造清单摘要）
- 主机/端口/前缀：客户端无 `8080`、`/api` 概念
- 分页语义：客户端 `offset`（累加）↔ 后端 `page/size`
- 字段：`song_id/artist_name/album_title/pic_big/lrclink` ↔ `id/artist/album/coverUrl`（无 `lrclink`）
- 时长单位：客户端假定秒、legacy `dt` 已是毫秒（差 1000 倍）
- 搜索参数：`query` ↔ `keywords`；歌词字段 `lrcContent` ↔ `data`
- 后端**无歌手接口**；客户端**无账号/歌单/收藏模块**
- 后端统一 `Result{code,message,data}`，客户端模型无 `code` → 无法识别业务错误
